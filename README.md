# Drone HUD – Dronovation Labs

An AR heads-up display for Snap SPECS that keeps a drone pilot's eyes on the drone.
Height, distance and battery sit beside the drone; at 30% battery the tag turns amber,
a line points home and a spatial chime plays; an edge arrow points back if the drone leaves view.

- Planned with the Devpost Learn skill pack: see `devpost/design-brief.md`
- Built by Snap's CLAD agents in Lens Studio 5.23.2 via the Lens Studio MCP
- Tested with LEAF: all 5 done criteria pass
- Runs in the Lens Studio preview with a virtual drone and simulated telemetry
